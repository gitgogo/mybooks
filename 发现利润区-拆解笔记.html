01全局信息

市场占有率神话已死——利润不来自份额，而来自每五年一次重塑的"以客户+利润为中心"的企业设计。
书名
《发现利润区》（The Profit Zone，全书约 16 万字）
作者
亚德里安·斯莱沃斯基、大卫·莫里森（美世咨询顾问），中文版序言落款 2002 年 2 月
核心论点
① 以产品为中心、追求市场占有率的旧秩序已失效，"无利润区"在全球蔓延；② 利润来自巧妙的"企业设计"，而非规模；③ 企业设计须每 5 年创新一次，否则利润区会转移走。
全书结构
三部分递进：第一部分（1-3章）立论+理论框架；第二部分（4-13章）9+3个创新者案例；第三部分（14-15章）因果机制+12问操作手册。

03第一部分 · 理论框架

第1章 · 市场占有率已经过时

利润区 / 无利润区 / 错误企业设计下的增长 / 创新者 / 企业设计的创新
市场占有率曾是利润的"指示器"，如今二者已脱钩；追求份额本身反而是制造无利润区的首要原因。
证据
历史强 1985—1995 年 IBM、GM、Sears、Kodak、US Steel、United Airlines 等份额领先者股市表现低于标普500； 数据中 10 家竞争者目标份额相加超 150%~170%（逻辑归谬）； 个案强 英特尔 1985 年主动退出存储芯片转向微处理器。
反常识
旧观念"高份额自然带来高利润"被推翻。创新者逻辑倒置——先问"客户要什么/利润从何而来"，再问"如何在这些盈利领域赢份额"，与传统"先份额后利润"次序完全相反。
关键概念
利润区（可赢利的经济活动领域）/ 无利润区（企业黑洞）/ 企业设计4要素（客户选择·价值获取·战略控制·业务范围）/ 战略控制点
作者自省
承认市场占有率"不会消失"——创新者也赢份额，只是把份额当结果而非目标；未一刀切否定份额，立场比标题克制。
引文
"提高无利润区中的市场占有率和获得增长无异于一种陷阱。"（原文）

第2章 · 以客户为中心的企业设计

以客户为中心的思想 / 价值链的转换 / 解读客户偏好 / 隐藏的偏好：客户经济系统 / 预测客户偏好
传统市场研究（问卷/满意度调查）是"回溯"的，无效；以客户为中心要求反转价值链（从客户→资产），并破解客户的"隐性偏好"（客户经济系统）。
证据
个案强 福特 vs 斯隆：1920年代客户偏好从"可靠便宜"转向"个性+贷款"，福特份额从55%暴跌至12%，斯隆金字塔设计胜出； 个案强 报表纸行业：纸上花1美元、相关流程花20美元，客户偏好从"纸"转向"电子表格系统"，催生新利润区。
反常识
客户最迫切的需求常是"隐性"的——客户自己都不清楚（如报表纸买家不知道总成本是纸的21倍）。供应商破解隐性需求=巨大盈利机会。
关键概念
客户经济系统（金钱+时间+抉择困扰的"大盒子"）/ X射线晶体学式多角度客户分析 / "能够定义未来的客户"（≠前沿客户）/ 价值链反转
作者自省
承认以客户为中心"难以实现"——资深高管被产品思维主导、企业成功后重心内移；不回避实施难度。
引文
"关键问题不是现在的客户偏好是什么……关键问题是客户未来的偏好是什么。"（原文）

第3章 · 利润是如何产生的

22种盈利模式 / 战略控制点指数 / 企业设计价值四指标
利润不是"自然产生"的，而是被"设计"出来的。22 种盈利模式 + 10 类战略控制点 + 4 个价值指标，构成可操作的诊断框架。
证据
分类归纳中 22种模式各配企业实例（FactSet/可口可乐/英特尔/迪士尼/微软）； 数据强 可口可乐vs宝洁vs全美航空四指标对比：销售利润率26%/9%/7%、资产效率0.7/0.6/1.0、战略控制9/4/1.5 → 市值/销售额比 7.0/3.0/0.3。
反常识
战略控制点有强弱之分——"品牌"只是中等控制（指数~5），"行业标准/价值链控制"才是顶级（指数9-10）；"没有战略控制点的企业设计就像舱底带洞的船"。
关键概念
22种盈利模式 / 战略控制点指数（10级） / 资产密集度（资产/销售额，越高越拖累利润） / 客户盈利能力（10-15%客户无利可图）/ 盈利心理学（节俭文化）
作者自省
坦承 22 种模式"有重叠"（售后模式与基础产品模式"类似但有根本差异"），承认分类非互斥；预言"未来会发现更多模式"。
引文
"即使最强大的利润工具也有可能被企业不必要的资产密集度所拖累。"（原文）

04第二部分 · 创新者案例

9+3 个案例是平行变体（每个创新者一种企业设计），不分主次递进。作者反复强调：不同创新者的设计"截然不同"，不存在万能模板，关键是创造力。每个案例下方标注其落地的盈利模式（对应第3章）。

第4章 · 通用电气（杰克·韦尔奇）

杰克·韦尔奇 GE / 解决方案企业设计
关键动作
3 次企业设计迭代：①1981"不做第一就做第二"（聚焦份额领先）→ ②1988"群策群力"（剔除流程冗余提效率）→ ③1990s"销售解决方案"（从卖产品转卖服务+融资）。把产品降为解决方案的组件。
前→后
市值 130亿 → 1620亿（1981→1996）；生产率年均增幅 2% → 4%+；GE资本资产 → 1860亿（美国第三大银行）；售后+融资贡献运营收入 40%。
落地模式
客户解决方案模式 + 售后模式（喷气引擎服务利润率超30%）
关键引言
GE 销售员不谈产品只问客户资金占用与产能损耗，两周后带回融资+仓储+全球支持方案，拿下全部塑料订单——"产品是产生利润的催化剂，非利润本身"。
失败/疑虑
"不做第一就做第二"遭内部强烈抵制，两年才见效；韦尔奇自承每次设计"都终将过时"，是过渡手段。

第5章 · 三位中层管理者（企业设计不止于CEO）

吉姆·多纳休 美登通信 / 直接到店解决方案
关键动作
发现客户10万套促销材料堆在仓库被当垃圾扔，转为"直接到店"解决方案（设计+制作+分发+数据维护一条龙），废除佣金改工资制。
前→后
营收 500万 → 1.2亿（1980→1997）；客户从1000家缩到<10家头部；销售代表每周省7小时。
落地模式
客户解决方案模式 + 风险-回报共享合同
失败/疑虑
内部改革"每走一步都很艰难"，有人"仍然不理解"；1989年一客户退回老路，4年浪费200万美元宣传材料后又回头。
吉姆·伯顿 包装箱公司 / 中层创新
关键动作
5年期固定价合同+租仓库保证及时交货；要求开发"1.2倍成本换2倍寿命"的耐用箱子，扭转"箱子越坏卖越多"的旧激励。
前→后
改进箱子分拣节省 15%；锁定可靠大客户。
落地模式
客户解决方案模式
卡丽·史密斯·考克斯 山德士制药 / 氯氮平系统
关键动作
抗精神分裂药1%致死率，未放弃药品而是建"每周验血+限量供药+家庭医疗+实验室+数据库"系统。先3地区→10地区→全国逐步验证。
前→后
全年 零死亡（之前每1000人死10人）；销量大增；数万患者恢复正常人生活。
落地模式
客户解决方案模式（系统替代产品改进）
失败/疑虑
承认改革有风险，靠逐步扩大验证；公司初始"有些担心"。

第6章 · 斯沃琪（尼古拉斯·哈耶克）

尼古拉斯·哈耶克 SMH / 产品金字塔企业设计
关键动作
三层金字塔：斯沃琪（低端防火墙）→中端→宝珀/欧米茄（塔尖利润）。零件从155个减到51个；用反常识市场测试证明"工资不是问题"；情感化产品+限量制造。
前→后
瑞士制表工人 9万 → 3万 被止血；1983-1992售 1亿块，1996再售1亿；SMH市值 → 38亿+；斯沃琪返修率<1%（行业3%）。
落地模式
产品金字塔模式 + 防火墙品牌
关键引言
三块同款手表标不同产地，意大利99%、瑞士97%消费者选瑞士制造——"工资不是问题，真正的问题是管理、创新、营销和生产"。
失败/疑虑
斯沃琪名是误打误撞（不知英文意为"清洁巾"）；斯沃琪汽车等扩张"可能会失败"；"没有惊天动地的失败，就难有重大进展"。

第7章 · 可口可乐（罗伯托·戈伊苏埃塔）

罗伯托·戈伊苏埃塔 可口可乐 / 管理价值链企业设计
关键动作
把"装瓶商"从最大障碍重新定位为首要客户。用HFCS省20%成本作筹码重签合同；1986成立CCE并剥离51%上市——控制装瓶商却不并入资产表（降资产密集度又融资11亿）；国际市场用支柱型装瓶商模式。
前→后
市值/销售额比 0.7 → 7.0（1980→1996）；运营利润 → 40亿（1995），80%来自国际。
落地模式
多单位系统模式（自动售货机/饭店每盎司5-8美分 vs 杂货店2美分）+ 管理价值链
失败/疑虑
两大失败如实记录：收购哥伦比亚影业（最终高价卖出算挽回）、新可乐（公众抵制后撤回）；整合装瓶商是"豪赌"，列出一连串"如果…怎么办"的未解风险。

第8章 · 嘉信理财（查尔斯·施瓦布）

查尔斯·施瓦布 嘉信理财 / 配电盘企业设计
关键动作
3次迭代：①1975折扣经纪（分离建议与交易）→ ②80s末服务投资咨询师（把行业眼中的"竞争对手"当客户/渠道）→ ③1992一源（OneSource，客户零费用、向基金公司收费的配电盘）。
前→后
市值 1.52亿 → 12亿（1987→1991）；传统单笔交易费8.5%→一源对客户 零费用；成第四大经纪公司。
落地模式
配电盘模式（自我壮大：参与者越多越有价值）
失败/疑虑
早期投资咨询师项目"刚开始并不成功…做出了一些无法实现的承诺"；1996通过银行提供一源"引起很大争议，即使拥护他的人也有异议"。

第9章 · 英特尔（安迪·格鲁夫）

安迪·格鲁夫 英特尔 / 领先两步企业设计
关键动作
退出立身之本DRAM转微处理器（裁员30%）；"征服行动"500项设计采用；同步开发三代芯片缩短周期；制造主板控制价值链；"内置英特尔"把客户从设备商转向终端用户。
前→后
开发周期 90周 → 44周；8086销量达摩托罗拉68000的 9倍（摩托产品更好但企业设计更差）；市值 30亿 → 1000亿。
落地模式
速度模式 + 价值链控制 + 品牌战略控制点
关键引言
"摩托罗拉以更好的产品赢得开门红，而英特尔凭借更好的企业设计获得了最后的胜利。"
失败/疑虑
退出存储器"从感情角度是艰难决策"（公司为此而创立）；"内置英特尔"在1991年"让人摸不着头脑"，是赌注；奔腾处理器缺陷亦是重大失误之一。

第10章 · 迪士尼（迈克尔·艾斯纳）

迈克尔·艾斯纳 迪士尼 / 利润乘数企业设计
关键动作
3级递进：盈利电影制作→卖座大片→利润乘数（同一IP经电影→录像→零售→主题公园→电视网络多次变现）。把迪士尼从"产品创造者"扩为"创造者+分销商"；自建迪士尼商店+收购ABC。
前→后
安德森一家旅行支出中迪士尼占比 20% → 75%（1984→1990）；迪士尼商店首年每平方英尺销售 1000美元（业内2-3倍），1988年10店→1998年 630店；门票18→28美元4年涨，年利润增 3.1亿。
落地模式
利润乘数模式 + 卖座大片模式
失败/疑虑
《木偶奇遇记》录像首试仅900万收益；欧洲迪士尼"许多假设出现致命错误…运营状况非常糟糕"；承认"成功本身"是内部威胁。

第11章 · 美国热电（乔治·哈特索珀罗斯）

乔治·哈特索珀罗斯 美国热电 / 分拆型企业设计
关键动作
反惯例分拆——分拆核心业务上市（非外围），且永不卖子公司股权。研发中心≠做研发而是新业务孵化器；热力学院促内部思想交流。
前→后
市值 6000万 → 80亿（1982→后）；市值/销售额比超 2.5:1；1993-96市值增近2倍。
落地模式
创业者模式（分拆对抗"规模不经济"）
失败/疑虑
分拆后研发部门"人去楼空"需收购替代；早期热力转换器"除了太空计划几乎无商业价值"——以客户为中心是被市场教训出来的。

第12章 · ABB集团（珀西·巴尼维克）

珀西·巴尼维克 ABB / 全球专家网络企业设计
关键动作
收购各地"通才"小厂→专业化重组（各专注最擅长的40%产品、放弃60%不赚钱产品，网络补齐）；本地优势+全球优势融合；5000利润中心让决策贴近客户；价值共享合同（福特奥克维尔3亿项目）。
前→后
原材料采购成本降 15-20%；约 1000公司+5000利润中心；交付时间 2-3月 → 4周。
落地模式
专业化模式 + 价值共享合同
失败/疑虑
巴尼维克自承技术创新"并未带来巨大竞争优势…12-18个月对手就能赶上"；承认网络面临"规模不一、内部冲突、不协调"的挑战。

第13章 · 微软（比尔·盖茨）

比尔·盖茨 微软 / 行业标准企业设计
关键动作
4次建标准：BASIC语言→MS-DOS→Windows→应用软件。核心手法：开放式标准（鼓励第三方开发）+ 消除转换壁垒 + 赢客户心理认同 + 先低价渗透后从升级获利。
前→后
市值 → 1700亿；Windows兼容软件 <1000款 → >30000款（1989→1996）；DOS毛利 80%；装机超1亿套。
落地模式

05第三部分 · 方法论

第14章 · 企业设计创新如何创造利润区

因果链条 / 利润悖论 / 重大错误 / 目标锁定
企业设计创新→财务绩效改善→估值提升→价值增长，构成正反馈因果链。但创新必伴随重大失误；最大失误是"目标锁定"——紧盯过时指标而忽略现实转移。
证据
数据中 9大创新企业 vs 标普500 vs 市场份额领先者（全美航空/伯利恒钢铁/DEC/福特/GE/IBM/Sears/联航/美钢）的市值增长对比； 类比中 俯冲投弹"目标锁定"——飞行员盯目标忘了高度，类比管理者盯过时份额指标撞向地面。
反常识
"利润总是在下降"的经典战略理论被创新者打破——其利润率"没有降低，甚至不是四平八稳，而是一直增长"，靠的是提高重复性收入占比（升级费/服务合同/管理费）。
关键概念
企业设计创新因果链 / 目标锁定（target fixation）/ 重复性收入 vs 交易性收入
作者自省
明确列出9家创新企业各自的重大失误（基德皮博迪/奔腾缺陷/新可乐/投资咨询师运营梦魇/产品1.0版/斯沃琪电信/欧洲迪士尼），"没有大失误就不会有大创造"——不粉饰创新代价。

第15章 · 利润区手册（12问操作指南）

12个递进问题，每个配案例示范。全书唯一的"可立即使用"工具。
  1. 我的客户是哪些人？——真正了解客户=能将他们划分为不同群体。多数管理者以为懂客户，实则不能细分。
    示范：可口可乐主要客户群=消费者/饭店和自动售货机/主要装瓶商/美国国内连锁店（不只"消费者"）。
  2. 客户的偏好如何变化？——客户需求非静止，新偏好催生新机遇。要同时看本行业和其他行业的偏好迁移。
  3. 哪些人应当是我的客户？——能否沿价值链跨一步服务客户的客户？创造性的客户选择是创新者成功关键。
    示范：ABB把竞争的当地工程公司纳入网络当客户，而非与其争当地项目。
  4. 如何为客户增加价值？——分析客户偏好，比对手更有效满足。问：对手能满足哪些？你能更好满足哪些？能更低成本满足哪些？
  5. 如何才能成为客户的首选？——让客户愿付溢价，需同时满足X/Y/Z偏好。
  6. 盈利模式是什么？——对应第3章22种模式中的哪一种？我们如何赚钱？
  7. 目前的企业设计是怎样的？——盘点4要素（客户选择/价值获取/战略控制/业务范围）现状。
  8. 真正的竞争对手是谁？——常非你以为的那个。
  9. 最难对付的竞争对手的企业设计是什么样的？——理解强者的设计逻辑。
  10. 下一个企业设计是什么样的？——利润区在转移，下一个5年设计是什么。
  11. 战略控制点是什么？——对应第3章10级指数，你的企业在哪一级？如何升级？
  12. 公司价值如何？——用4指标（销售利润率/预期利润增长率/资产密集度/战略控制指数）量化诊断，市值/销售额比是综合反映。

作者特别提示："不要快速浏览，要花几个小时静静思考"——工具的价值在于使用深度而非知晓；可与其他管理者一起讨论更易完成。

09论证薄弱处 / 证据局限

本书框架有力，但证据基础有明显可质疑之处，阅读时须警惕：

  • 时代/地域局限：案例集中在 1990s 美国大公司，结论在数字经济/中国市场/平台经济的可推广性存疑。
  • 22种盈利模式分类边界模糊：作者自承模式"有重叠"，配电盘/行业标准/基础产品三者边界不清，作为诊断工具的互斥性不足。

  • 哈耶克"工资不是问题"的市场测试样本小：仅三国消费者、单一价格档，可推广性存疑。
  • 翻译质量：豆瓣读者指出"翻译不是很自然"，部分长句晦涩。
